# Campfinder

Find flat wild-camping spots for big tents in Norway. See [PLAN.md](PLAN.md).

## Run locally

```sh
docker compose up -d --wait   # PostGIS on localhost:5432
cd web
cp .env.example .env
pnpm install
pnpm dev                      # http://localhost:3000
```

On an Apple Silicon Mac, enable Rosetta in Docker Desktop (Settings → General →
"Use Rosetta for x86_64/amd64 emulation"): the official PostGIS image is
amd64 only.

`GET /api/health` checks that the app can reach PostGIS.

## Layout

```text
docker-compose.yml   PostGIS
web/                 TanStack Start app (React, shadcn/ui, MapLibre)
  src/routes/        pages and API routes
  src/components/    UI components (ui/ is generated by shadcn)
  src/lib/           map setup, basemaps, regions, place search
  src/server/        server-only code (database)
```
